# HR Employee Attendance Dashboard

## 📌 Project Overview
This project is an interactive Power BI dashboard designed to analyze employee attendance, working hours, and leave patterns. It provides HR and Operations teams with a clear view of workforce productivity, late arrivals, and work mode distribution.

## 🛠️ Tools Used
* **Power BI Desktop** (Data Visualization, DAX)
* **CSV Dataset** (55,000+ employee attendance records)

## 📊 Dashboard Features
* **Modern UI:** Light background with clean white KPI cards and dark blue borders.
* **KPI Cards:** Total Employees, Average Working Hours, and Total Late Arrival Minutes.
* **Dynamic Slicer:** Filter the entire dashboard by Department.
* **Visualizations:** 
  - Employee Count by Department (Column Chart)
  - Work Mode Split: Office vs. Remote (Donut Chart)
  - Late Arrivals by Shift (Bar Chart)
  - Leaves by Type (Pie Chart)
  - Gender Split (Column Chart)

## 💡 Key Insights
* The Engineering department has the highest number of employees.
* 72% of the workforce prefers working from the office.
* The "General" shift experiences the highest volume of late arrivals, indicating a need for schedule review.
